1.1. Abstract
This document defines the visual identity of VoiceGate's three screens (Test Bench, Call
Review, Risk Report): palette, typography, contrast/legibility requirements, and the shared
visual language for verdict badges, findings, and calibration charts. The two-variant
palette below is inherited unchanged from the sibling DarkStrategy_XParadoxX project (prior
002_game_aesthetics.txt, preserved in git history) as a starting default only; it is
explicitly NOT a confirmed VoiceGate brand decision and remains open to revision.

1.2. Key Words
palette, dark theme, light theme, contrast, legibility, word wrap, accessibility, typography,
verdict badge, Test Bench, Call Review, Risk Report, inherited default, unconfirmed brand.

1.3. Executive Summary
VoiceGate reuses, as a placeholder default, the two selectable color-palette variants
inherited from the sibling game project: Variant A (Dark, near-black background with
warm-pink text) and Variant B (Light/Inverted, pink background with near-black text), sharing
one accent/border color. All three VoiceGate screens (Test Bench, Call Review, Risk Report)
must render legibly in both variants and must never communicate a Pass/Fail/Flag verdict by
color alone. This palette carries no brand authority for VoiceGate; it is reused purely to
avoid blocking UI work while a dedicated VoiceGate brand identity remains unconfirmed (see
001_voice_transcription_concept.txt Section 1.9, open items).

1.4. Key Findings
1.4.1. The palette values (#000000/#FFACE9 background-text pair, #B76E79 shared accent) are
carried forward unchanged from the sibling project's aesthetics document as an inherited
default only, per explicit user directive 2026-08-03; they are not a VoiceGate brand
decision and must be labeled as such wherever displayed to stakeholders.
1.4.2. Variant A (Dark) is background #000000 / text #FFACE9; Variant B (Light) inverts this
to background #FFACE9 / text #000000. Both variants use #B76E79 for accents, borders, and
dividers.
1.4.3. Legibility, readability, and word-wrapping are non-negotiable requirements, unchanged
in principle from the inherited baseline, applied now to transcript text, rule citations, and
verdict rationale rather than card/tile text.
1.4.4. Verdict state (Pass/Fail/Flag) must never be communicated by color alone; a badge
shape/label/icon must duplicate every color-coded signal, given the compliance-critical
nature of this product.
1.4.5. Any future VoiceGate-specific brand refresh supersedes this document's palette
sections without requiring changes to Sections 1.7-1.9 (typography, screen visual language,
motion), which are treated as VoiceGate-native content, not inherited.

1.5. Philosophical Preamble
A palette is a contract of legibility between the tool and the compliance reviewer using it;
in a product whose entire purpose is flagging risk, an illegible or ambiguous verdict display
would itself be a compliance failure. VoiceGate borrows the sibling project's dark, high-
contrast aesthetic as a convenient, already-vetted starting point, but treats it explicitly
as scaffolding, not identity: every reused hex value in this document carries an inherited-
default label so no future contributor mistakes convenience for confirmation.

1.6.3. Shared Accent and Border Rule
1.6.3.1. #B76E79 is used identically in both variants for panel borders, selection outlines,
dividers, and the provisional wordmark.
1.6.3.2. The active variant is a per-session, user-selectable Settings toggle (see
004_voicegate_ui_navigation.txt); it is not tied to any run or verdict state.
1.6.3.3. Verdict colors (Pass/Fail/Flag) are not defined by this document; a future addendum
must declare them explicitly, following the same inherited-default-vs-confirmed labeling
discipline established here.

1.6.4. Contrast, Legibility, and Word-Wrap Requirements
1.6.4.1. #000000-on-#FFACE9 and #FFACE9-on-#000000 both satisfy strong contrast for body
text; transcript timestamps and small metric badges must use a minimum 14px-equivalent size.
1.6.4.2. All text containers (transcript lines, finding annotations, rule-citation tooltips,
Suggested Patch Adviser explanations) must wrap at word boundaries and must never clip or
silently truncate.
1.6.4.3. Verdict and finding state must never be communicated by color alone; borders, icons,
and labels must duplicate every color-coded signal, per accessibility guidance in
0000_documentation_standards.txt.

1.7. Typography
1.7.1. One geometric display face for headings; one highly readable sans-serif for interface
text, including transcript display.
1.7.2. Monospaced text is reserved for raw transcript timestamps and rule-ID citations, to
aid scanability and audit review.
1.7.3. Numeric displays (pass/fail/flag counts, calibration scores) use a tabular-figure
treatment so values do not visually reflow.

1.8. Screen Visual Language (Test Bench, Call Review, Risk Report)
1.8.1. Test Bench: persona/scenario selectors and the live transcript panel share the base
palette; an active-run indicator uses the shared accent color plus a distinct icon, never
color alone.
1.8.2. Call Review: the dual-channel transcript is rendered as two visually distinct speaker
lanes (agent under test vs. simulated caller); inline findings are shown as verdict badges
(Pass/Fail/Flag label + icon + border treatment) anchored to the exact transcript line they
apply to.
1.8.3. Risk Report: failed calls are listed against the specific rule text they violate; a
before/after re-run diff view and a judge-calibration chart share the base palette and
typography, with the chart using pattern/texture in addition to color to remain legible for
color-vision-deficient reviewers.
1.8.4. Every verdict badge (Pass/Fail/Flag) uses a distinct shape and icon in addition to
color, per 1.6.4.3.

1.9. Motion and Animation Restraint
1.9.1. Animation is restrained: transcript auto-scroll, subtle badge-appear transitions, and
a live-run pulse indicator are permitted; continuous background motion, screen shake, and
full-surface gradients are avoided, carried forward unchanged from the inherited baseline's
stated aesthetic exclusions.

1.10. Logo Concept
1.10.1. A provisional wordmark "VoiceGate" is used without an accompanying mark; the sibling
project's fractured-geometry logo concept is explicitly NOT carried forward, since it is
thematically tied to the game brand. A dedicated VoiceGate mark remains an open item pending
brand confirmation (see 1.4.1).
