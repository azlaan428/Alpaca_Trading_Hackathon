1.1. Abstract
This document is the authoritative parking lot for every feature, mode, or scoring capability
explicitly excluded from the VoiceGate MVP (001_voice_transcription_concept.txt Section 1.9),
replacing the sibling project's wishlist (018_future_wishlist_items.txt, preserved in git
history), so that good ideas are recorded rather than lost and scope-creep requests during
implementation are routed here instead of silently expanding the MVP.

1.2. Key Words
wishlist, deferred features, backlog, stretch goals, post-hackathon roadmap, scope
discipline, live production monitoring, multi-language personas, real-time coaching.

1.3. Executive Summary
Every item below was considered during the source concept chat
(voice_transcription_concept/voice_chat_concept.md) or this documentation pass and
deliberately deferred, not rejected. Items are grouped into deferred modes/features, deferred
compliance/scoring complexity, and deferred content expansion, each with a one-line rationale
for deferral.

1.4. Key Findings
1.4.1. Deferral is not deletion: every item here remains a candidate for a post-hackathon
roadmap and must be re-evaluated against 001_voice_transcription_concept.txt Section 1.9
before being promoted into an active specification document.
1.4.2. The largest deferred category is live/production-facing capability (live production
monitoring, real-time coaching mode) that the MVP intentionally simplifies away in favor of
offline, run-based gauntlet testing per 016_voicegate_operating_modes.txt.
1.4.3. Multi-language persona support is the most frequently anticipated content-expansion
item, restated here as the canonical wishlist entry for that theme.
1.4.4. Any promotion of a wishlist item to active scope requires updating
001_voice_transcription_concept.txt Section 1.9 and the relevant mechanics/mode document in
the same change, per the version-control discipline in
0000_documentation_standards.txt Section 1.6.7.

1.5. Philosophical Preamble
A wishlist is where ambition goes to wait its turn. Recording a deferred idea with its
rationale protects the vertical-slice-first design pillar (003_voicegate_philosophy.txt
Section 1.6.5) without pretending the idea was never worth having.

1.6. Deferred Modes and Features
| Item | Rationale for Deferral |
|------|---------------------------|
| Live production monitoring (continuous testing against a live production agent) | MVP only requires offline, run-based scripted gauntlet and adversarial fuzzing modes |
| Real-time coaching mode (in-call guidance to a live human agent) | Out of scope for a red-team/compliance test bench MVP; a distinct product surface |
| Always-on autonomous fuzzing without human-reviewed run boundaries | Explicitly deferred per 016_voicegate_operating_modes.txt Section 1.10 |
| Multi-tenant user accounts, profiles, authentication | Not required for a single-team hackathon-scale MVP |
| Ranked/competitive benchmarking across multiple vendors' agents | Depends on a shared benchmark corpus not yet defined |

1.7. Deferred Compliance/Scoring Complexity
| Item | Rationale for Deferral |
|------|---------------------------|
| Automated legal-review upgrade of VERIFICATION-FLAGGED citations to confirmed | Requires a qualified legal reviewer sign-off per 003_voicegate_philosophy.txt Section 1.8, not an engineering task |
| Additional statutory regimes beyond EU AI Act Article 50 and California SB 243 | 028_statutory_ruleset_integration.txt currently scopes to the two cited, verification-flagged statutes only |
| Automatic ingestion/scraping of a company's live Terms & Conditions page | MVP assumes a manually supplied T&C snapshot per run |
| Cross-run statistical significance testing on judge-calibration drift | 010_voicegate_run_statistics.txt tracks the trend; formal significance testing is deferred pending more run history |

1.8. Deferred Content Expansion
| Item | Rationale for Deferral |
|------|---------------------------|
| Multi-language personas (non-English simulated callers) | MVP ships English-only personas from 027_persona_archetype_definitions.txt |
| Additional persona archetypes beyond the current catalog | MVP ships the archetypes carried forward from the source concept chat only |
| Additional scenario categories beyond Crisis/Emotional, Minor/Age-Sensitive, Adversarial-Refund, Standard/Happy-Path | 025_scenario_persona_catalog.txt ships exactly these four categories at MVP |
| Procedurally generated scenario scripts | Not required for the MVP vertical slice; current scenarios are pre-authored |

1.9. Explicit Non-Goals
1.9.1. VoiceGate will not auto-apply a Suggested Patch Adviser recommendation during a live
or scripted run; any AI-assisted remediation remains advisory-only per
016_voicegate_operating_modes.txt Section 1.9.3, permanently, not just for the MVP.
1.9.2. VoiceGate will not upgrade a VERIFICATION-FLAGGED external citation (statute or
tribunal precedent) to confirmed status without an explicit legal-review sign-off, per
003_voicegate_philosophy.txt Section 1.8.
