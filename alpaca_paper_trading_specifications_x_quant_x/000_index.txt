1.1. Abstract
This file is the master index of the X Quant X specification corpus. It registers all 32
specification files in alpaca_paper_trading_specifications_x_quant_x/, summarizes their domain and
rewrite phase, and serves as the entry point for any agent or contributor navigating the
corpus. It was the last file rewritten in the three-phase corpus rewrite (per
CHATS/2026-08-26_alcapa-spec-rewrite-PLAN.md §4.4). This index must be updated whenever a
file is added, removed, or renumbered, per Section 1.6.7 of 0000_documentation_standards.txt.

1.2. Key Words
corpus, document registry, index, phase-1 foundations, phase-2 domain-core,
phase-3 product-layer, rewrite status, specification files, X Quant X.

1.3. Executive Summary
The X Quant X corpus consists of 32 specification files: one documentation standards baseline
(0000), one opening-day master prompt (0001), and 30 topical files (001-031, excluding 032
which does not exist). All 32 files have been rewritten from the prior X Quant X/X Paradox X
domain to the X Quant X quantitative paper-trading domain per the plan in
CHATS/2026-08-26_alcapa-spec-rewrite-PLAN.md. The rewrite was executed in three phases:
Phase 1 (foundations: 003, 005, 006, 007, 019, 021, 023, 024), Phase 2 (domain core: 008,
009, 011, 012, 013, 014, 016, 017, 020, 022, 025, 026, 027, 028, 030, 031), Phase 3 (product
layer: 001, 002, 004, 010, 015, 018, 029, 0000, 0001, 000).

1.5. Philosophical Preamble
A quantitative trading platform that cannot account for its own decisions in writing has no
standing to account for the market's decisions in code. The X Quant X specification corpus
exists because rigor applied only at the code layer — not the documentation layer — produces
systems whose implicit assumptions erode silently under regime changes, personnel changes, or
the simple passage of time. Every specification file in this corpus is written as a
first-class engineering artifact: version-controlled, changelog-tracked, cross-referenced,
and required to resolve contradictions with peer documents rather than papering over them.
This index is the capstone of that discipline: it is not a README, not a glossary, and not a
placeholder — it is a governed registry of every obligation the corpus places on its
implementers, present and future.
