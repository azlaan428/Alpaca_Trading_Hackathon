1.1. Abstract
This document defines the visualization development standards for X Quant X, specifying
required chart types, Plotly/Matplotlib conventions, color palette tokens, accessibility
requirements, export formats, and the dashboard layout for the X Quant X paper-trading
monitoring interface.

1.2. Key Words
visualization, Plotly, Dash, Matplotlib, equity curve, drawdown, regime probability,
correlation heatmap, signal score, portfolio weights, risk gate log, dark mode, WCAG AA,
color palette, chart export.

1.3. Executive Summary
X Quant X uses Plotly (with Dash for the interactive dashboard) as the primary visualization
library. Seven chart types are required for the MVP dashboard: equity curve, drawdown
waterfall, regime probability bar, correlation heatmap, signal score time series, portfolio
weights treemap, and risk-gate trigger log table. All charts use a dark-mode primary theme
with the X Quant X brand color tokens. WCAG AA contrast minimum is enforced. Charts export
as PNG (static) and HTML (interactive). All chart code lives in xquantx/dashboard/ and
never contains trading logic.

1.4. Key Findings
1.4.1. Seven MVP chart types cover the full monitoring surface: equity performance (equity
curve + drawdown), regime state (regime probability bar), correlation structure (correlation
heatmap), signal confidence (signal score time series), allocation (portfolio weights
treemap), and risk audit (risk-gate trigger log).
1.4.2. Dark-mode is the primary theme: background #1a1a2e (deep navy), text #e0e0e0, accent
grid lines #2a2a4a.
1.4.3. Brand accent color #FFACE9 (Rose/Pink) is reserved exclusively for ALERT states --
REDUCE/BLOCK/FLATTEN verdicts, drawdown warning thresholds, and stress-regime highlights.
It must not be used for normal-state data series.
1.4.4. All charts are generated with Plotly graph objects (not plotly.express) to maintain
full control over layout and styling.
1.4.5. Every chart has a title, axis labels, legend, and a source annotation
("X Quant X | {session_id} | {mode}").

1.5. Philosophical Preamble
A visualization embedded in a monitoring dashboard is a claim about the current state of
the portfolio and risk posture; an unlabeled or unsourced chart is a claim nobody can
audit. This matters more, not less, in a quantitative trading context: a risk-gate trigger
log and an equity drawdown chart are themselves evidence, and evidence that cannot be traced
to a session ID and data source is not actionable evidence.

1.6. Required Chart Types
1.6.1. Equity Curve:
- Chart type: Plotly line chart
- X-axis: datetime (from timestamp_ns converted to UTC datetime)
- Y-axis: equity ($)
- Two series: portfolio equity (primary line, color #7ec8e3), risk-free rate baseline
  (dashed, color #4a4a6a)
- Annotation: peak equity watermark; current drawdown percentage
- Source: PortfolioSnapshot.equity per bar

1.6.2. Drawdown Waterfall:
- Chart type: Plotly waterfall or area chart (shaded area below zero)
- X-axis: datetime
- Y-axis: drawdown (% from peak, displayed as negative values)
- Color: normal drawdown #7ec8e3 (blue); drawdown > 10% warn threshold #FF9800 (orange);
  drawdown > 15% critical (FLATTEN trigger) #FFACE9 (rose/pink alert)
- Source: computed from PortfolioSnapshot.equity using max watermark

1.6.3. Regime Probability Bar Chart:
- Chart type: Plotly stacked horizontal bar chart (one bar per time point, stacked by
  regime probability)
- X-axis: probability (0 to 1)
- Each segment: labeled with regime ID (R01-R12) and color-coded per regime category
  (R01/R02/R11 = green tones; R03/R04 = orange/red tones; R05/R07 = red/FFACE9 alert
  tones)
- Source: RegimeState.regime_probabilities per bar

1.6.4. Correlation Heatmap:
- Chart type: Plotly heatmap
- Rows and columns: symbols in the portfolio
- Cell values: rolling 20-day pairwise correlation (CrossAssetSignalOperator output)
- Color scale: RdYlGn diverging (red = -1, yellow = 0, green = +1); correlation > 0.7
  annotated as potential concentration risk
- Source: CrossAssetSignalOperator output per bar

1.6.5. Signal Score Time Series:
- Chart type: Plotly multi-line chart (one line per active SignalOperator)
- X-axis: datetime
- Y-axis: signal score [-1, +1] with zero reference line
- Line colors: one distinct color per operator (no color reuse across operators)
- Confidence bands: +/- confidence displayed as shaded area around each signal line
- Source: Signal.signal_score and Signal.confidence per bar per operator

1.6.6. Portfolio Weights Treemap:
- Chart type: Plotly treemap
- Nodes: symbols, sized by |position_weight|
- Color: green tones for long positions, red tones for short positions
- Center label: equity ($ value) and % weight per node
- Source: AllocationVector and PortfolioSnapshot.positions per bar

1.6.7. Risk-Gate Trigger Log Table:
- Chart type: Plotly table
- Columns: timestamp, rule_id, verdict, symbol, measured_value, threshold
- Row highlight: BLOCK = orange background, FLATTEN = #FFACE9 background,
  REDUCE = light orange
- Source: AUDIT_LOGS/ RISK_GATE_DECISION entries for the session

1.7. Color Palette Tokens
| Token | Hex | Usage |
|-------|-----|-------|
| background-primary | #1a1a2e | Chart and dashboard background |
| text-primary | #e0e0e0 | All text, axis labels, annotations |
| grid-line | #2a2a4a | All chart grid lines |
| series-equity | #7ec8e3 | Equity curve, normal-state data |
| series-benchmark | #4a4a6a | Benchmark/baseline lines |
| alert-warn | #FF9800 | Drawdown 10-15%, moderate warning |
| alert-critical | #FFACE9 | Drawdown > 15%, FLATTEN, BLOCK verdicts |
| regime-bull | #4CAF50 | R01, R02, R11 regime segments |
| regime-bear | #F44336 | R03, R04, R07 regime segments |
| regime-neutral | #9E9E9E | R06, R08, R09, R10, R12 segments |

1.8. Accessibility Requirements
1.8.1. WCAG AA contrast minimum: all text on background must achieve >= 4.5:1 contrast
ratio. #e0e0e0 on #1a1a2e achieves ~14:1 (passes).
1.8.2. Color-blind safety: all series that convey meaning through color must also use
distinct line styles (solid, dashed, dotted) or marker shapes.
1.8.3. All charts have alternative text descriptions for screen reader compatibility
(Plotly `alt` parameter or accompanying markdown description).

1.9. Export Formats
1.9.1. PNG: static export via plotly.io.write_image() with width=1920, height=1080,
scale=2.
1.9.2. HTML: interactive export via plotly.io.write_html() with full_html=True,
include_plotlyjs='cdn'.
1.9.3. All exports are saved to
AUDIT_LOGS/{session_id}/charts/{chart_name}_{timestamp}.{ext}.

1.10. Dashboard Layout
The Dash dashboard is organized into six panels:
- Panel 1 (top): Equity Curve + Drawdown Waterfall (2 charts, side by side)
- Panel 2 (middle-left): Regime Probability Bar Chart (full-width, updated live)
- Panel 3 (middle-right): Signal Score Time Series (one line per active operator)
- Panel 4 (bottom-left): Portfolio Weights Treemap
- Panel 5 (bottom-middle): Correlation Heatmap
- Panel 6 (bottom-right): Risk-Gate Trigger Log Table

1.15. Conclusion
The seven-chart MVP dashboard covers the full monitoring surface of X Quant X: equity
performance, drawdown, regime state, correlation structure, signal confidence, allocation,
and risk audit. All charts use the dark-mode color tokens defined in §1.7; the
alert-critical #FFACE9 token is reserved exclusively for ALERT states and must not appear
in normal-state data series. All chart code is isolated in xquantx/dashboard/ with no
trading logic.
