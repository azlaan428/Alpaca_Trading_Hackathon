1.1. Abstract
This document defines the canonical market-scenario catalog for X Quant X. It specifies
the twelve canonical market-regime scenario types (R01-R12), their defining characteristics,
typical feature signatures, and the regime state vector conventions used by
MarketRegimeOperator implementations. It is the authoritative source for regime identifiers
referenced throughout the specification corpus and platform code.

1.2. Key Words
market scenario, regime type, R01 through R12, bull-quiet, bear-trending, high-volatility,
macro-shock, scenario catalog, regime identifier, regime state vector, hidden Markov model,
Bayesian inference.

1.3. Executive Summary
X Quant X recognizes twelve canonical market-scenario types, identified by codes R01-R12.
Each scenario type is characterized by a set of measurable market features (VIX range, trend
direction, correlation structure, volume profile, macro indicator direction) and maps to a
named regime archetype (defined further in 027_xquantx_regime_archetypes.txt). The scenario
catalog is the lookup table used by MarketRegimeOperator to assign posterior probabilities to
each regime type at each bar.

1.4. Key Findings
1.4.1. Twelve canonical regime types are sufficient to cover the range of market conditions
relevant to the X Quant X MVP scope (equity + ETF paper trading).
1.4.2. Regime identifiers are always string codes R01-R12; integer ordinals or unnamed enum
values are not permitted at schema boundaries.
1.4.3. Each scenario type has a defined "typical feature signature" -- a set of measurable
indicator ranges that distinguish it from neighboring regimes -- used to calibrate likelihood
functions in Bayesian and HMM regime inference.
1.4.4. The scenario catalog is declared in config/regimes.toml; MarketRegimeOperator reads
this at startup and uses it as the regime taxonomy.
1.4.5. Every bar, MarketRegimeOperator emits a RegimeState with a probability distribution
over all 12 regimes (sums to 1.0 +/- 1e-9); the scenario catalog defines what each non-zero
probability weight means.

1.5. Philosophical Preamble
A market-scenario catalog is not a prediction. It is a vocabulary. By naming twelve regime
types and defining what distinguishes them, the platform gives every downstream operator a
shared language for conditional behavior: "in macro-shock, block new longs; in bull-quiet,
weight momentum signals higher." Without a named catalog, regime-conditional logic would be
an unlabeled array of thresholds -- unmaintainable, inconsistent across operators, and
untestable.

1.6. Scenario Catalog
The twelve canonical regime types:

| ID  | Label                  | Defining Characteristics                                                          |
|-----|------------------------|-----------------------------------------------------------------------------------|
| R01 | bull-quiet             | Positive trend, low volatility (VIX < 15), normal volume, positive breadth,       |
|     |                        | positive macro                                                                    |
| R02 | bull-volatile          | Positive trend, elevated volatility (VIX 15-25), above-average volume, mixed      |
|     |                        | breadth                                                                           |
| R03 | bear-trending          | Negative trend, moderate-to-high volatility (VIX 20-30), increasing volume,       |
|     |                        | negative breadth                                                                  |
| R04 | bear-capitulation      | Severe negative trend, very high volatility (VIX > 30), volume spike, extremely   |
|     |                        | negative breadth, high correlation across assets                                  |
| R05 | high-volatility        | Elevated volatility (VIX > 25) without a clear trend direction; VIX term          |
|     |                        | structure inverted                                                                |
| R06 | low-liquidity          | Compressed volume, wide bid-ask spreads, reduced trade count; typical around      |
|     |                        | holidays or pre-announcement halts                                                |
| R07 | macro-shock            | Sudden macro event (rate surprise, geopolitical shock); fast regime shift within  |
|     |                        | 1-3 bars; all assets correlated negatively                                        |
| R08 | correlation-breakdown  | Intra-market correlations significantly below historical norms; assets that        |
|     |                        | usually move together diverge                                                     |
| R09 | sector-rotation        | Capital rotating between sectors; individual sector ETFs diverge while broad      |
|     |                        | index remains flat                                                                |
| R10 | mean-reversion         | Low autocorrelation of returns; Hurst exponent < 0.5; oscillating price action    |
|     |                        | around a mean                                                                     |
| R11 | momentum-continuation  | High autocorrelation of returns; Hurst exponent > 0.5; trending price action with |
|     |                        | increasing volume confirmation                                                    |
| R12 | rate-hike-cycle        | Elevated short-term rates; inverted or flat yield curve; rate-sensitive sectors   |
|     |                        | (real estate, utilities) underperforming                                          |

Per-scenario feature signatures (§1.6.1-§1.6.12):

1.6.1. R01 bull-quiet
VIX < 15; 20-day RSI > 55; MACD positive; advancing issues / declining issues ratio > 1.5;
ATR below 12-month mean; macro indicators (GDP growth positive, unemployment declining).

1.6.2. R02 bull-volatile
VIX 15-25; strong positive trend (50-day MA > 200-day MA); high volume relative to 20-day
average; elevated ATR; breadth mixed.

1.6.3. R03 bear-trending
Price below 50-day MA and 200-day MA; RSI < 45; MACD negative; ATR above mean; declining
issues > advancing issues.

1.6.4. R04 bear-capitulation
VIX > 30; Price > 2 standard deviations below 20-day mean; volume > 200% of 20-day average;
cross-asset correlation > 0.7; negative news sentiment spike.

1.6.5. R05 high-volatility
VIX > 25; no directional trend (RSI near 50); ATR > 200% of 6-month mean; term structure of
VIX inverted (spot > 3-month).

1.6.6. R06 low-liquidity
trade_count < 25th percentile of 60-day history; bid-ask spread > 200% of 30-day mean;
volume < 10th percentile.

1.6.7. R07 macro-shock
VIX spike > 30% in < 3 bars; simultaneous divergence of equity/bond/FX/commodity in a
single direction; news sentiment score < -0.7.

1.6.8. R08 correlation-breakdown
Rolling 20-day pairwise correlation across major sectors < 0.3 when 12-month baseline > 0.6;
sector ETF dispersion elevated.

1.6.9. R09 sector-rotation
Sector ETF momentum signals diverge (at least 3 sectors in top-quintile vs bottom-quintile);
SPY relatively flat; rolling 5-day sector return standard deviation elevated.

1.6.10. R10 mean-reversion
Hurst exponent (estimated over 60 bars) < 0.45; returns autocorrelation lag-1 < -0.2;
rolling RSI mean-reverting around 50.

1.6.11. R11 momentum-continuation
Hurst exponent > 0.55; positive autocorrelation lag-1 > 0.2; volume expanding with trend;
MACD histogram consistently positive or negative.

1.6.12. R12 rate-hike-cycle
Fed Funds rate or 2-year yield rising over past 3 months; 2s10s spread compressed or
negative; REITs and utilities sector momentum < 0.

1.7. Scenario ID Naming Convention
All scenario identifiers are exactly the codes R01 through R12 (uppercase R, two-digit
zero-padded integer). No other identifiers may be used at schema boundaries. The regime_id
field in RegimeState, Signal, and PortfolioSnapshot always contains one of these twelve
codes. Additions to the catalog require a new spec revision and changelog entry.

1.8. Using the Catalog in Operators
MarketRegimeOperator reads config/regimes.toml which maps each R0X code to: (a) the prior
probability for Bayesian initialization, (b) the likelihood function parameters for Bayesian
inference, and (c) the signal weight multipliers w_i(r) for SignalAggregationOperator. The
catalog is immutable at runtime.

1.13. Conclusion
This document converts the market-scenario catalog from a high-level concept into a strict
operational contract suitable for implementation, testing, and audit. The twelve regime codes
(R01-R12) provide a shared vocabulary across all X Quant X operators, enabling deterministic,
testable regime-conditional behavior without unlabeled threshold arrays.
